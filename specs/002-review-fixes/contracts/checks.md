# Contract: the check for each fix

Each fix lands with these checks, written as "when …, then …" in the named file through
`tests/helpers.sh`. **Fails first** is the half that must be seen failing on the code before the
change (the PR says so, FR-022); **guard** halves pass before and after and are not presented as
failing-first evidence. Corrections to 001's entries are in [research.md](../research.md) C1.
